# TODO-app
A simple to-do list or a schedule for completing tasks. If you have already finished them cross off or delete; else, it will remain forever: Tutorial: Click the circle on the left to cross off a task; if you want to delete it, click the X on the right. you can delete all completed tasks, view pending tasks, and clear all completed.
